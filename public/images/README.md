# Images

Drop files at these paths — they appear on the site automatically, no code changes needed.
Until a file exists, a clean placeholder (your initials / the project name) is shown instead.
`.jpg`, `.jpeg`, `.png` and `.webp` all work.

| What | Path | Shape | Suggested size |
| --- | --- | --- | --- |
| Your photo | `public/images/profile.jpg` | Portrait 4:5 (shown square on phones, so keep your face centred) | 1000 × 1250 |
| Project screenshot | `public/images/work/<slug>.jpg` | 16:10 desktop screenshot of the site's home page | 1600 × 1000 |

Project slugs (from `src/data/projects.ts`):

- `planngo`
- `trustloop`
- `imaginex`
- `makeup-studio`
